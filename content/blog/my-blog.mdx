I wanted to write a second blog post to reflect on the things I learned while building this website and growing as a developer.

## Building the portfolio

This project helped me practice working with Next.js, Tailwind CSS, and markdown-driven content. I learned how to make a blog system that automatically publishes new `.mdx` files just by adding them to `content/blog/`.

## What I learned

- How to structure content using frontmatter metadata like `title`, `date`, `excerpt`, `tags`, and `category`.
- How the blog page and individual post pages are generated from the `app/blog` route.
- How to use React components to render reusable elements like project cards and social icons.

## What’s next

I want to keep writing more posts about what I learn every week, including coding problems, project updates, and tips for other students starting in software engineering.

Thanks for reading my second post — I hope this site helps me keep tracking my progress and sharing it with others.
